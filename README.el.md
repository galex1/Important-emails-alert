# Important e-mails alert

Μικρή desktop εφαρμογή που παρακολουθεί λογαριασμό POP και ειδοποιεί για νέα σημαντικά emails μέχρι να τα επιβεβαιώσεις. Προαιρετικό Slack webhook. Χτισμένη με [tinyjs](https://tinyjs.app/).

English README: [README.md](./README.md)

## Δυνατότητες

- Περιοδικός έλεγχος POP3/POP3S
- Ειδοποιήσεις που επαναλαμβάνονται μέχρι «Το είδα»
- Εικονίδιο στο tray με πλήθος αδιάβαστων
- Καρτέλες Εισερχόμενα / Διαβασμένα / Spam, αναζήτηση, θέμα dark·light·system
- Σήμανση spam → μπλοκ αποστολέα (χωρίς νέες ειδοποιήσεις)· αναίρεση ανά πάσα στιγμή
- Προαιρετικό Slack Incoming Webhook σε συγκεκριμένο κανάλι
- Γλώσσα UI: Ελληνικά ή Αγγλικά
- Credentials τοπικά σε SQLite (οθόνη Ρυθμίσεις)

## Απαιτήσεις

- [tinyjs](https://tinyjs.app/) ≥ 0.50
- Linux (beta), macOS ή Windows
- Mailbox με ενεργό POP (προτείνεται app password)

## Εκτέλεση

```bash
tinyjs dev
```

Πακετάρισμα:

```bash
tinyjs build
```

## Πρώτη ρύθμιση

1. Άνοιξε **Ρυθμίσεις**
2. Συμπλήρωσε POP host, θύρα (συνήθως `995`), χρήστη, κωδικό, TLS
3. Προαιρετικά βάλε Slack Incoming Webhook URL
4. Αποθήκευση και **Δοκιμή σύνδεσης**
5. **Έλεγχος τώρα** ή περίμενε το διάστημα polling

## Spam

- **Spam** σε ένα μήνυμα μπλοκάρει τη διεύθυνση αποστολέα
- Νέα mail από τον ίδιο αποστολέα μπαίνουν στο Spam χωρίς ειδοποίηση / Slack
- **Όχι spam** (ή **Ξεμπλοκάρισμα** στη λίστα) επαναφέρει τον αποστολέα και τα μηνύματα ως αδιάβαστα

## Απόρρητο

- Τα δεδομένα μένουν στο τοπικό data directory της εφαρμογής (SQLite)
- Ο κωδικός δεν επιστρέφεται ποτέ στην UI μετά την αποθήκευση
- Χωρίς cloud λογαριασμό· το Slack χρησιμοποιείται μόνο αν ορίσεις webhook
